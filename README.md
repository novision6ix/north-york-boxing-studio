# North York Boxing Studio — Landing Page

Client copy of template `landing-startbootstrap-001` (Biblioteca-Templates).
The master template was NOT modified.

## Structure
- `index.html`      Content and structure
- `css/styles.css`  Base theme (Bootstrap) — do not edit
- `css/custom.css`  Client design (dark / sport, responsive)
- `js/config.js`    WhatsApp number, Instagram, phone — EDIT THIS
- `js/scripts.js`   Wires the buttons to config.js
- `assets/img/`     `logo.svg`, `photo-1.jpg`, `photo-2.jpg`, `photo-3.jpg`, `../favicon.ico`
